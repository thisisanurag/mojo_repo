# Hardware Managment System

• Designed and deployed a full-stack web application for a Hardware-as-a-Service (HaaS) system, utilizing Python Flask, ReactJS, and MongoDB, with cloud deployment on Heroku/Azure Web App.

• The application streamlines hardware resource management by enabling secure user authentication, efficient inventory tracking, and real-time monitoring of hardware check-ins and check-outs. It optimizes resource allocation and utilization while ensuring scalability and seamless project management.

Techstack used : ReactJS, Javascript, Python, HTML, CSS, MongoDB, Heroku, Flask
